# customer-segmentation-rfm
📊 Objective
Segment customers based on purchasing behavior


In this project, both K-Means Clustering and RFM Segmentation are used to analyze customer behavior.
Although they may seem similar, they serve different but complementary purposes.


🧠 Methodology
Data Cleaning
RFM Analysis
K-Means Clustering

📈 Result
| Cluster | Segment    |
| ------- | ---------- |
| 0       | At Risk    |
| 1       | Regular    |
| 2       | Recent     |

💡 Business Insight
High-value customers show signs of inactivity
Majority customers are low-frequency buyers

🛠 Tools
Python
Pandas
Scikit-learn
Microsoft Power BI
